# Market Intelligence & Watchlist Dashboard

Et moderne, interaktivt Business Intelligence dashboard bygget med HTML, CSS, JavaScript og Chart.js.

## Funktioner
- **Interaktiv kursgraf:** Viser kursudvikling med intervallerne 1D, 5D, 3M, YTD, 1Y, 3Y, 5Y og MAX.
- **Finansielle nøgletal:** Udstiller realtidskurs, dagens udsving, P/E, Forward P/E og 200 Day Moving Average (SMA).
- **Teknisk trend:** Vurderer automatisk Bullish/Bearish momentum baseret på 200 SMA.
- **Lokal persistens:** Gemmer overvågningslisten og API-nøglen lokalt i browseren (`localStorage`).

## Kom i gang
1. Åbn websiden via GitHub Pages.
2. Opret en gratis konto på [Finnhub.io](https://finnhub.io/) og hent din API-nøgle.
3. Indsæt nøglen i feltet øverst og tilføj tickers som f.eks. `NVDA`, `SPY` eller `AAPL`.
